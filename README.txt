# Student Performance Prediction — Colab-ready

1. Open https://colab.research.google.com/
2. Choose File → Upload notebook.
3. Upload `Student_Performance_Prediction_Complete.ipynb`.
4. Choose Runtime → Run all.
5. Read the markdown explanations and review the outputs/graphs as they appear.

The notebook generates its own reproducible synthetic dataset, so no manual CSV upload is required. The separate CSV is supplied for inspection or independent use.

No GPU is required. Runtime is normally only a few minutes; the 30–45 minute estimate includes reading explanations and reviewing outputs. The data is synthetic and must not be represented as real student records.
